3년 8개월간 데이터 분석 · 지표 체계 · 운영 개선을 맡았고, 지금은 AI 서비스를 직접 만들어 배포하고 있습니다.<br>
AI 에이전트에 여러 작업을 나눠 맡기고, 가설 검증과 최종 판단은 제가 맡는 방식으로 일합니다.

## AI를 다루는 방식

사용자가 실제로 쓰는 AI 경험과, 운영할 수 있는 구조를 함께 만듭니다.

- **모델을 이해한 뒤 고릅니다.** 탐지(YOLO·SSD)·세그멘테이션(U-Net)·생성(GAN·i2v 영상)·언어 모델 파인튜닝(KoBART)을 직접 돌려 본 경험으로, 문제에 맞는 모델과 API를 정합니다.
- **데이터·코드·프롬프트를 분리합니다.** 사실은 원장과 DB에, 계산은 코드에, 판단은 프롬프트와 평가 기준에 둡니다. 같은 입력이면 같은 결과가 나오고, 틀리면 어디가 틀렸는지 찾을 수 있습니다.
- **작게 만들어 실제 동작으로 확인합니다.** 기준을 먼저 정하고 돌아가는 최소 버전을 만든 뒤, 비용·응답 속도·리소스를 같이 봅니다.
- **AI 결과를 자연스러운 사용 경험으로 만듭니다.** 행동 흐름, 결과를 고치는 방식, 피드백 상태와 애니메이션 감도를 UI에서 다루되, 필요한 수준의 완성도와 경제성을 우선합니다.
- **AI·사용자·협업자가 같이 읽을 수 있게 전달합니다.** 전사 리포팅과 광고 기획·PT·협업 감독 경험을 바탕으로 목적·입출력·판단 기준·다음 행동을 문서로 남깁니다.
